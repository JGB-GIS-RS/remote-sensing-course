# Ejemplo · Informe Técnico No. 02

Esta carpeta está reservada para el informe técnico de referencia utilizado para establecer el estándar editorial de la **Serie Técnica de Teledetección**.

## Tema del prototipo

**Efecto del tamaño y balance de las muestras de entrenamiento en la clasificación de coberturas mediante Support Vector Machine y Random Trees.**

El prototipo sirve como referencia de:

- estructura editorial;
- jerarquía de secciones;
- presentación de figuras, tablas y ecuaciones;
- separación entre Resultados, Discusión, Recomendación técnica y Conclusiones;
- documentación de datos y reproducibilidad.

El archivo editable `.docx` se incorporará cuando se defina la versión oficial para distribución estudiantil.

> Este ejemplo no constituye una solución para los casos del Banco de TAREAS y no debe utilizarse para imponer subsecciones idénticas a problemas metodológicamente diferentes.
