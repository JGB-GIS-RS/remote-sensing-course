# T3 · Transformaciones y estructura espectral

## Pregunta guía

> **¿Qué transformación o representación espectral permite caracterizar mejor las estructuras y coberturas presentes en el área estudiada?**

## Núcleo técnico

T3 estudia cómo reorganizar y sintetizar la información multiespectral para revelar estructura, contrastes y redundancia en los datos.

## Contenidos principales

- composiciones de bandas;
- firmas espectrales;
- índices espectrales cuando sean pertinentes;
- análisis de componentes principales (PCA);
- Tasseled Cap Transformation (TCT);
- enmascaramiento de nubes y control de calidad cuando corresponda.

## Enfoque analítico

El trabajo no se limita a ejecutar una transformación. El estudiante deberá interpretar qué información concentra PC1, qué contrastes contienen los componentes posteriores, cuánta varianza explican, qué significan los loadings cuando se utilicen y qué interpretación física tienen brightness, greenness y wetness en TCT.

El objetivo es determinar si la representación transformada añade información o claridad respecto de las bandas originales y bajo qué condiciones.

## Flujo conceptual

`bandas originales → firmas espectrales → PCA / TCT / índices → comparación → interpretación`

## Frontera con T4

La clasificación no debe dominar T3. Si se utiliza alguna separación temática como apoyo exploratorio, esta no sustituye la TAREA de clasificación, validación y modelación que corresponde a T4.
