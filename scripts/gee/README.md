# Google Earth Engine

Esta carpeta contiene scripts generales de Google Earth Engine utilizados por el curso.

Los scripts estrechamente vinculados con un caso se almacenan preferentemente dentro de la carpeta del caso correspondiente para mantener juntos **enunciado, datos, código y documentación**.

## Convenciones

- JavaScript para el Code Editor de Google Earth Engine: `.js`.
- El encabezado debe indicar TAREA/caso, propósito, entradas, salidas y supuestos principales.
- Las colecciones, niveles de producto, máscaras de calidad y factores de escala deben quedar explícitos.
- Los scripts docentes deben distinguir entre procesamiento exploratorio y procesamiento científico definitivo.
