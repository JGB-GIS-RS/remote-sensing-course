# Plantilla oficial · Serie Técnica de Teledetección

Esta carpeta contiene la **Plantilla Oficial v1.0** para los Informes Técnicos de la Serie Técnica de Teledetección.

## Archivos

- [`Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v1.0.docx`](Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v1.0.docx) — copia editable de trabajo para preparar el informe.
- [`Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v1.0.dotx`](Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v1.0.dotx) — plantilla reutilizable de Microsoft Word.

Ambos archivos materializan la misma identidad editorial. La versión `.docx` puede abrirse y editarse directamente; la versión `.dotx` permite crear un documento nuevo basado en la plantilla sin modificar el archivo maestro.

## Uso

La plantilla conserva la composición visual del prototipo editorial cerrado: encabezado de la Serie, jerarquía tipográfica, numeración de líneas, estilos de títulos, pies de figura, tablas, referencias y numeración de páginas.

El texto de orientación que aparece **en gris y cursiva** es texto guía. Debe reemplazarse o eliminarse antes de entregar el informe. Los textos entre corchetes, por ejemplo `[Título científico e informativo...]` o `Informe Técnico No. [XX]`, son campos de sustitución y no deben permanecer en la versión final.

El número del Informe Técnico, semestre, fecha, autores y correos deben actualizarse para la TAREA correspondiente.

## Arquitectura editorial

Los grandes apartados se mantienen en todos los informes:

- Resumen
- Palabras clave
- 1. Introducción
- 2. Área de estudio y datos
- 3. Metodología
- 4. Resultados
- 5. Discusión
- 6. Recomendación técnica
- 7. Conclusiones
- Disponibilidad de datos y código
- Referencias

Las **subsecciones** se adaptan al problema técnico de cada TAREA; no deben conservarse subtítulos de ejemplo cuando no sean pertinentes.

## Figuras, tablas y contenido de ejemplo

Los cuadros de figura y la tabla incluidos son únicamente **marcadores editoriales** para mostrar el estilo esperado. Deben reemplazarse por evidencia real del trabajo o eliminarse cuando no correspondan.

No existe una cuota fija de figuras o tablas. Cada elemento debe aportar evidencia necesaria y ser citado en el texto antes de su aparición.

## Extensión y normas

La preparación del informe se rige por la [`Guía para autores v1.0`](../docs/guia_general/guia_para_autores.md). Como norma general, el límite es de **8 páginas para el PDF completo**, desde la primera página con título y autores hasta la última página de Referencias, salvo excepción explícita del enunciado de una TAREA.

No deben modificarse arbitrariamente los márgenes, tipografías, encabezados, numeración de líneas ni demás componentes visuales para ganar espacio.
