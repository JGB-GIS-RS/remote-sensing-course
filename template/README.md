# Plantilla · Serie Técnica de Teledetección

Esta carpeta alojará la plantilla oficial del **Informe Técnico de Teledetección** y su documentación de uso.

La versión de referencia conserva la arquitectura editorial común de la Serie y será publicada aquí una vez finalizada la guía para autores.

## Estructura principal

- Resumen
- 1. Introducción
- 2. Área de estudio y datos
- 3. Metodología
- 4. Resultados
- 5. Discusión
- 6. Recomendación técnica
- 7. Conclusiones
- Disponibilidad de datos y código
- Referencias

Las subsecciones se adaptarán a cada TAREA sin alterar esta estructura principal.
