# Plantilla oficial · Serie Técnica de Teledetección

Esta carpeta contiene la **Plantilla Oficial v2.0** para los Informes Técnicos de la Serie Técnica de Teledetección.

## Archivo oficial

- [`Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v2.0.docx`](Plantilla_Oficial_Serie_Tecnica_Teledeteccion_v2.0.docx) — documento editable para preparar los informes de la Serie.

La plantilla v2.0 se deriva directamente del **Informe Técnico No. 02 de referencia**, cuya versión final consolidó la identidad visual y editorial de la Serie. De este modo, el documento que utilizan los estudiantes y el ejemplo terminado comparten el mismo sistema de estilos, márgenes, encabezados, numeración de líneas, tablas, pies de figura, ecuaciones y referencias.

## Cómo utilizarla

Abra una copia del archivo `.docx` y reemplace los textos entre corchetes. Los estilos ya están definidos para título, autores, metadatos, resumen, texto principal, títulos de primer y segundo nivel, figuras, pies de figura, tablas, ecuaciones, disponibilidad de datos y código y referencias.

Los ejemplos de figura, tabla y ecuación cumplen una función **editorial**, no metodológica. Deben reemplazarse por el contenido real del informe o eliminarse cuando no correspondan. Las subsecciones 3.1, 4.1 y otras equivalentes deben adaptarse a la TAREA concreta.

No debe utilizarse el documento para alterar arbitrariamente márgenes, tipografías, encabezados o numeración con el fin de ganar espacio.

## Arquitectura editorial común

Elementos preliminares no numerados:

- Título y autores
- Resumen
- Palabras clave

Secciones numeradas:

1. Introducción
2. Área de estudio y datos
3. Metodología
4. Resultados
5. Discusión
6. Recomendación técnica
7. Conclusiones

Elementos finales no numerados:

- Disponibilidad de datos y código
- Referencias

Las subsecciones se adaptan al problema de cada TAREA.

## Documento de referencia

El informe terminado que define el estándar visual puede consultarse en [`../examples/informe_tecnico_02/`](../examples/informe_tecnico_02/). El ejemplo sirve para observar la aplicación real de los estilos; **no constituye una solución de los casos ni una estructura metodológica que deba copiarse de forma mecánica**.

## Extensión y normas

La preparación del informe se rige por la [`Guía para autores v1.0`](../docs/guia_general/guia_para_autores.md). Como norma general, el límite es de **8 páginas para el PDF completo**, desde la primera página con título y autores hasta la última página de Referencias, salvo excepción explícita del enunciado de una TAREA.
